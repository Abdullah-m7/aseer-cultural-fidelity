# External Expert Outreach Principle

The scientifically strongest first contact is a **small calibration request**, not a collaboration pitch.

The expert should be asked to identify where the benchmark is too strict, too broad, or missing local nuance. The first packet therefore contains five cases and fifteen invariant judgments, hides model outcomes, and does not ask for access to students, industry partners, institutional data, or introductions.

No external person's name should be added to the repository as reviewer, adviser, collaborator, or endorser without explicit consent.

If a domain expert chooses to engage, the next response should show exactly what changed because of their feedback. That turns the relationship into substantive intellectual exchange rather than networking by extraction.
