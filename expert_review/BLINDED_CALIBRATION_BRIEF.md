# Domain-Expert Calibration Brief v0.1

## Purpose

This is a **design-calibration exercise**, not a request to evaluate an AI model and not a request to endorse the project.

We are building a source-anchored instrument for a narrow question: when AI translates, markets, modernizes, or operationalizes Aseer culture for tourism and hospitality, which changes are legitimate adaptation and which become cultural misrepresentation?

The first expert pass intentionally withholds all model results to reduce anchoring.

## What we ask you to review

Five cases were selected before any held-out model run. For each proposed invariant, the worksheet asks four short judgments:

1. **Source adequacy** — adequate / needs supplement / unsuitable.
2. **Invariant verdict** — valid as written / too strict / too broad / incorrect / needs local nuance.
3. **Must-surface verdict** — should omission count as culturally misleading for this task? yes / no / context-dependent.
4. **Severity if violated** — critical / material but noncritical / minor / context-dependent.

An optional note field is the most valuable place to flag a missing local nuance or a mistake a fluent outsider might make.

## Calibration principle

We are not trying to freeze culture or punish modernization. A contemporary hotel, product, or tourism experience may adapt local heritage. The benchmark should penalize false provenance, silent identity substitution, and misleading claims — not creativity itself.

## Expected time

The worksheet contains **15 invariant rows across 5 cases** and is designed for roughly 15–20 minutes.

## Research boundary

This first pass is methodological consultation. No reviewer name, quotation, or identifiable response should be presented as research data or public endorsement without explicit permission. If expert judgments are later analyzed as study data, the project should obtain the appropriate ethics determination first.
