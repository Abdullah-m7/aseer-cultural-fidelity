# Expert review package

This folder contains the **pre-review** calibration materials for Stage 003A.

The package is deliberately outcome-blinded: Stage 002 model results are not included in the expert brief or worksheet. The goal is to validate the construct before using expert judgments to support model-comparison claims.

## Frozen review subset

The five cases are:

- `ACF-FOOD-001` — Haneeth / luxury hospitality adaptation;
- `ACF-FOOD-002` — Areeka / international breakfast adaptation;
- `ACF-TOUR-001` — World Region of Gastronomy / global marketing;
- `ACF-ART-001` — Al-Qatt Al-Asiri / hospitality interior adaptation;
- `ACF-ARCH-001` — heritage-village-inspired resort marketing.

This gives culinary heritage, destination positioning, visual heritage, and architecture without asking a reviewer to process the full benchmark.

Do not overwrite the v0.1 worksheet after external feedback. Preserve it and create a new post-review version so every expert-driven change remains auditable.
